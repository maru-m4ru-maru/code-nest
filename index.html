Features

作るための機能を、ひとつの場所に。

Notebookを制作の中心にして、コード・実行・プレビュー・共有をつなげます。

01

Notebook

コードやMarkdownなどをセルとして整理。アイデアと実装を一緒に残せます。

02

Browser Runtime

ブラウザ上でコードを実行。環境構築をシンプルに。

03

Code Preview

HTML作品をその場でプレビュー。編集から確認までスムーズに。

04

Share

コードと完成したプレビューを分けてURLで共有できます。

Code Nestからのおやくそく

Code Nestの共有機能は、現在Cloudflare Workersの無料プランで運用しています。共有を短時間に大量に行うなど、サーバーへ負荷をかける使い方はやめてね。1日の上限に達すると、Code Nestを使っているほかの利用者にも影響する可能性があります。みんなで気持ちよく使えるように、必要なときだけ共有してください🙏
